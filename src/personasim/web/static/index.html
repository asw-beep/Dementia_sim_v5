Interview guide
  • Orientation — “What day is it today?” · “Where are we right now?”
  • Delayed recall — “Remember these three words…”, then ask for them a few turns later
  • Recent memory — “What did you have for breakfast?” · “What did we talk about earlier?”
  • Remote memory — “Where did you grow up?” · “Tell me about your wedding.”
  • Sequencing — ask one question with several parts
  • Listen for — word-finding pauses, repetition, whether she notices her own lapses
